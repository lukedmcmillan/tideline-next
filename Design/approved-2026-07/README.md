# Approved July 2026 Visual Reference Suite

1. These files are the approved July 2026 visual reference suite.
2. Current application code remains the implementation base.
3. The HTML files govern visual outcome and information architecture, but do not prove that displayed data or functionality is live.
4. Public marketing and authenticated platform use related but distinct treatments.
5. The homepage may use cream, Newsreader, Plus Jakarta Sans, DM Sans and restrained coral.
6. Authenticated platform pages use the deep green sidebar, white working canvas, Newsreader headings, DM Sans interface text and semantic green, amber and red.
7. DM Mono is not part of the approved system.
8. Old mockups must not override these files.
9. Factual examples, prices, dates and product claims must still be verified before publication.
10. The dashboard has minor token differences from the remaining platform pages. These should be reconciled during implementation without changing its approved content hierarchy.
11. Design changes must be assessed against this complete suite rather than against one page in isolation.
